# Hypertaks Plugin Bundle for Goose

## Install

Install the Hypertaks plugin bundle through **Goose Skills Marketplace** or import the reviewed Hypertaks recipe from this repository.

The package preserves exactly five canonical public skills and does not add optional MCP capabilities unless the user enables them separately.

## Update

Update through the same Goose skill or recipe mechanism used for installation.

## Uninstall

Remove only the Hypertaks skill or recipe package. Preserve unrelated Goose extensions and configuration.

## Compatibility

Official native plugin-compatible integration: `PASS`.
