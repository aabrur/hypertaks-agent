# Hypertaks Plugin for OpenClaw

OpenClaw can install compatible Claude, Codex, and Cursor plugin bundles directly from Git.

## Install

```bash
openclaw plugins install git:github.com/aabrur/hypertaks-agent@main
openclaw plugins enable hypertaks
```

## Inspect and update

```bash
openclaw plugins inspect hypertaks --runtime
openclaw plugins update hypertaks
```

## Uninstall

```bash
openclaw plugins uninstall hypertaks
```

## Compatibility

Official native plugin compatibility: `PASS`.
