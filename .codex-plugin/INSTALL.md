# Hypertaks Plugin for Codex

## Install

```bash
codex plugin marketplace add https://github.com/aabrur/hypertaks-agent.git
```

Open `/plugins`, locate `hypertaks@hypertaks-marketplace`, then enable it.

## Update

Use the Codex plugin marketplace upgrade flow, then refresh the installed Hypertaks plugin.

## Uninstall

Disable or remove `hypertaks@hypertaks-marketplace` from `/plugins`.

## Compatibility

Official native plugin compatibility: `PASS`.
