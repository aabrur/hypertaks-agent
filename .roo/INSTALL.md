# Hypertaks Plugin for Roo Code

Roo Code is archived. This guide targets its final compatible environment.

## Install

Import the five Hypertaks plugin skill folders into:

```text
.roo/skills/
```

or:

```text
.agents/skills/
```

## Update and uninstall

Pin the Hypertaks plugin bundle to the archived Roo environment. Remove only the five Hypertaks folders when uninstalling.

## Compatibility

Official archived native compatibility: `PASS`.
